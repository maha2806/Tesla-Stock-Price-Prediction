# Tesla Stock Price Prediction

## Project Overview
Predicting Tesla stock closing prices using Machine Learning.

## Dataset
Tesla historical stock market data from Yahoo Finance.

## Features Used
- Open
- High
- Low
- Adj Close
- Volume
- Price Range
- Daily Return
- MA_7
- MA_30

## Models Used
1. Linear Regression
2. Random Forest Regressor
3. XGBoost Regressor

## Evaluation Metrics
- MAE
- RMSE
- R² Score
