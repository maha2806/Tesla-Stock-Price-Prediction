# Tesla Stock Price Prediction

## Project Overview

This project predicts Tesla's closing stock price using Machine Learning techniques.

## Dataset

Tesla historical stock price dataset containing:

- Open
- High
- Low
- Close
- Adj Close
- Volume

## Feature Engineering

Created additional features:

- Price Range
- Daily Return
- 7-Day Moving Average
- 30-Day Moving Average

## Models Used

1. Linear Regression
2. Random Forest Regressor
3. Decision Tree Regressor

## Evaluation Metrics

- MAE
- RMSE
- R² Score

## Results

| Model | R² Score |
|---------|---------|
| Linear Regression | 1.00 |
| Random Forest | 0.726 |
| Decision Tree | 0.729 |
